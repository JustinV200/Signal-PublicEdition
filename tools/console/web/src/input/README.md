# input

The input line. `InputLine` owns the draft (placeholder "Message Claude…"), sends on Enter or the Send button (switching to Chat, where the reply lands; both are off while no Claude session is linked, and Send's tooltip says why: `no Claude session yet` or `Claude session closed`; with an empty draft Send is off but solid-bordered, its tooltip `type a message first`. The reason is never a caption, so typing never moves the buttons), opens command mode from the Commands button, recalls history on Up/Down (`useHistoryRecall` over the last 50 sends in `history.ts`, kept in localStorage so they survive closing the window; storage that is blocked or throws leaves recall to the current page load), grows 1 to 8 rows (`useAutoGrow`), hosts the command palette in command mode (its actions go through the state's confirm gate, like the buttons) and swaps in `ConfirmLine` (the question in 600 with `Yes` and `No` buttons, hints `y` and `n`) while an action asks first: a full calibrate, or loading a save or showing its live version over a drawing (see `state`'s confirm rule). The y / n keys themselves are global (`keys`). `focusInput()` lets other packages return focus here.

Public API: `index.ts`. Depends on `state`, `palette`, `ui`, `api` (types).
