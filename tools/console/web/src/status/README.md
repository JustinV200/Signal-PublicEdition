# status

The status line. `StatusLine` reads the store and renders the app name (quiet: 600, `--fg-2`, no glow) plus the connection in words (`--fg`), the owner's away state while not Here, `HealthPointer`, `Freshness` and the Help button; then `TabRow` (`tabs/TabRow.tsx`, with `tabs/Tab.tsx`): Scope, Chat with `2 new` while it has rows the owner hasn't seen (`state`'s `chatNewCount`; no words otherwise), Voice with the phase, Boards with one short word for what is up (`to-do list`, `idle`, `drawing`, `night` or `off`), Tasks with `1 needs you` or else `3 active`, System, and Setup only when the shell's `showSetupTab` prop says so (a picked tool unfinished, or Setup open). Each `Tab` is a `--border`-outlined button, name in `--fg` and status in `--fg-2`, whose shortcut is its tooltip, not on its face, the active one filled, bold and glowing; the row wraps rather than scrolls, so every tab stays in view. While the console tour's bar shows, its stop's tab also reads `◂ tour` (ui's triangle turned to point back, then the word, at every width). The row is a `tablist` with a roving tabindex: only the active tab is in the Tab order, Left / Right move focus (wrapping), Home / End jump to the ends, and Enter or Space opens the focused tab (arrows never switch the view by themselves).

- `connectionWords(state, now)` is the connection in words, as parts joined by a faint `·`: `Claude · working 0:42 · 5 agents`, `Claude · idle`, `Claude · quiet for 12 min (interrupted?)`, `Claude · state unknown until its next turn` (or `Claude · state unknown · turn hook missing`, in the warning style, while the console's Turn hook check fails: the cause from `state.health`; its tooltip has the check's sentence and where the fix is), `No Claude session · run "console claim" in Claude Code` (never claimed), `Claude session closed` (claimed, but its session is gone: `orchestrator.alive` false), `Console server not answering · retrying in 3s`, `Connecting…`. Never claimed, closed, quiet and server down are in the warning style, each with its own words. Its `title` (the tooltip) is the full text, then `Session: <label>, linked 3d ago` (the age from `orchestrator.claimedAt`; `Session linked 3d ago` unlabelled; no age when the time is missing or doesn't parse) or where the fix is. Its `spoken` is the same state with no clock or count (`Console server not answering`, `Claude · working`, `Claude · waiting on agents`, `Claude · quiet (interrupted?)`; the rest as shown), which the status line puts in a visually hidden `role="status"` region (`.srOnly`), so a screen reader hears a change once instead of the line every second.
- `awayWords(away)` and `titleAwayWords(away)` put the state snapshot's `away` block (the brief's away mode, or sleep mode) in words. `awayWords` is System's YOU: `Here`, `Away until Thu 17:00`, `Away (ends by itself in 3 days)` (`AWAY_DEFAULT_DAYS`, the brief's default) or `Asleep (sleep mode)`. `titleAwayWords` is the title row's, as `{word, until, tooltip}`: `Away` (with ` until Thu 17:00` when an end was given, its own span that drops out below 720px) or `Asleep`, shown in 600 and never shrunk; the tooltip points at YOU's `I'm back` for Away and says sleep mode decides Asleep. Null (nothing shown) while Here or unreadable.
- `HealthPointer` shows only while one of the console's own checks (`state.health`) isn't ok, leaving out the two the page already words live (`LIVE_ELSEWHERE`: the claim, which the connection words say, and the whiteboard, which the Boards tab says; health is read only at load, on System and on Refresh, so a pointer for them would go stale or show all day): a button naming the first problem, a failing check before one that needs a look (`firstProblem`), `✗ Turn hook: missing · see System` (a half disc for a check that only needs a look), which opens System. At phone widths it shortens to an ellipsis rather than pushing Help off the screen.
- `Freshness` shows only when something is wrong: `no update for 25s` once the stream has been quiet past 20 s (in `--warn` too), or `updated 3s ago` while the server is not answering, each beside a labelled `Refresh` button that re-reads everything now. While all is well neither shows; the `Refresh` command (Ctrl+K) does the same. `api`'s `isStreamStale(syncedAt, now)` and `time`'s `shortAge(ms)` decide and word the staleness; the scope's `NO SIGNAL 25s` uses them too, so both go stale together.
- `turnCauseWords(turn, checks, now)` puts Claude's turn state in words (`working 0:42 · 5 agents`, `waiting on 5 agents`, `idle`, `quiet for 12 min (interrupted?)`, `state unknown until its next turn`) and adds `state unknown`'s cause from the console's checks (`state unknown · turn hook missing` while the Turn hook check fails). It builds on the module's own `turnWords`; the scope uses it, and the connection words use the same pieces (`failingTurnHook`, `HOOK_MISSING_WORDS`, `turnWords`), so they agree.
- `titleWords.ts`: the counts the tabs and the browser window's title share, `newWords` (`2 new`) and `needsYouWords` (`1 needs you`), each null at 0, and `windowTitle(chatNew, needsYou)`, `(2 new, 1 needs you) Signal console` with a part dropped at 0 and `Signal console` (`APP_NAME`, also the title row's and the sign-in page's name) alone when both are 0. `app`'s shell sets `document.title` from it, and the scope's CHAT row uses `newWords`.
- `PhaseDot` is the voice dot (`ui`'s disc or ring, pulsing while thinking, bars while speaking); the phase word beside it carries the meaning.
- `startedByWords(startedBy)` words the server's `voice.startedBy` (`console` or `external`) as `started by the console` or `started outside the console`, for the Voice view and the scope.

Public API: `index.ts`. Depends on `api`, `state`, `time` and `ui`.
