# agents.options

Option builders for the lead, critic and Q&A sessions: `lead_options`, `critic_options`, `qa_options` (in `roles.py`), on top of the shared `role_options` (`base.py`) and the role prompts (`prompts.py`). See [../README.md](../README.md). Depends on `security`, `kit`, and the agents `fetch`, `nested` and `chamber_server` modules.
